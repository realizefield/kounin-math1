ST01　集合　解説と例題

第3章　集合の基礎

1．集合とは

集合とは、はっきりした「ものの集まり」「グループ」のことです。

例えば、「1から5までの数」をひとまとめにしたグループに A という名前をつけると：

A = { 1, 2, 3, 4, 5 }

このように { } （中カッコ）で囲んで書きます。
この A グループの仲間は、1、2、3、4、5 の5人。
この1つ1つの仲間のことを 要素（ようそ） といいます。

📖 言い換え
「要素」＝「仲間」「メンバー」と思ってOK。
A = { 1, 2, 3, 4, 5 } なら、1 は A グループの仲間、6 は A グループの仲間ではない。

「仲間」を表す記号

a ∈ Aa は A の仲間である（要素である）
a ∉ Aa は A の仲間ではない（要素ではない）
💡 記号の覚え方
・∈ ：開いた口が左にある → グループの中に「入っている」イメージ
・∉ ：斜めの線が「入っていない」サイン
例題 1
A = { 1, 2, 3, 4, 5 } のとき、次の□に入る記号は？
（1）　3 □ A　　（2）　6 □ A
日本語で考えましょう
（1） 3 は A グループ {1,2,3,4,5} の仲間？→ 仲間です → ∈
（2） 6 は A グループ {1,2,3,4,5} の仲間？→ 仲間ではない（リストにない）→ ∉
💡 戦略：高認では「∈・∉」よりも、次の「⊂・⊃・∩・∪」のほうがよく出ます。記号の意味だけ押さえれば十分です。

2．包含関係（A⊂B、A⊃B）

集合 A の仲間（要素）が全員、集合 B の仲間にも入っているとき、A は B の部分集合といい、次のように書きます。

A ⊂ B　（AはBに含まれる）

逆の向きで書くこともできます。

B ⊃ A　（BはAを含む）

記号の覚え方

⊂ の開いた方が大きいグループです。
A ⊂ B → A（小さい）⊂ B（大きい）
A ⊃ B → A（大きい）⊃ B（小さい）
例題 2 ＜過去問 R6-1 類題＞
A = { 2, 4, 6, 8, 10 }、B = { 4, 8 } のとき、A □ B に入る記号は？
① ∈　　② ∋　　③ ⊂　　④ ⊃
日本語で考えましょう
B の仲間は 4・8。この2人は、A グループ {2,4,6,8,10} の中にもいる？
→ 2人ともA の仲間に入っています。
つまり B の仲間は全員、A の仲間でもある → A は B を「含んでいる」
答え：④ ⊃

3．共通部分 A∩B と 和集合 A∪B

共通部分 A∩B（キャップ・かつ）

A グループと B グループの両方の仲間を集めた集合。
「A の仲間でもあり、B の仲間でもある」人だけが集まったグループ。

A ∩ B　＝　「A かつ B」
🌟 身の回りの例で考えてみよう
クラスのみんなで、
・A = 野球が好きな人のグループ
・B = サッカーが好きな人のグループ
とすると…
A∩B（A かつ B）は 野球もサッカーも両方好きな人！
どちらか片方だけ好きな人は入りません。
塗りつぶし部分が A∩B
（両方好きな人の場所）

⚠ 空集合 ∅（くうしゅうごう）

もし A グループと B グループに 仲間が1人もダブっていない としたら、
A∩B（両方の仲間）はどうなるでしょうか？

🌟 身の回りの例で考えてみよう
運動会で：
・A = 赤いたすきをしたグループ（80人）
・B = 白いたすきをしたグループ（80人）
がいます。

A∩B（赤いたすきかつ白いたすき）の人は何人？
→ 0人！　赤と白を同時にすることはできません。

このように、仲間が1人もいない集合を 空集合（くうしゅうごう） といい、記号 ∅ で表します。

赤たすき ∩ 白たすき　＝　∅
（両方を同時にする人は誰もいない）
2つの円が離れている → A∩B＝∅（共通の仲間なし）
💡 ポイント
・∅ は「からっぽの集合」「仲間が0人の集合」のこと
・読み方は「くうしゅうごう」または「ファイ」
・A∩B＝∅ なら、A と B には共通する仲間が1人もいないという意味

他にも空集合になる例
・偶数全体 ∩ 奇数全体 ＝ ∅（同時に偶数で奇数の数はない）
・正の数全体 ∩ 負の数全体 ＝ ∅（同時にプラスでマイナスの数はない）
例題（空集合・過去問 R6-2 類題）
A を偶数全体の集合、B を奇数全体の集合とするとき、
「A □ B = ∅」が成り立つ。□に入る記号は次のうちどれ？
①　⊂　　②　⊃　　③　∪　　④　∩
日本語で考えましょう
A は偶数（2、4、6、8…）の仲間。B は奇数（1、3、5、7…）の仲間。
同時に偶数でも奇数でもある数はある？ → ない（どんな整数も偶数か奇数のどちらか）
→ A と B には共通の仲間が1人もいない
→ A ∩ B（A かつ B）が空っぽ → A ∩ B ＝ ∅
答え：④ ∩

和集合 A∪B（カップ・または）

A グループと B グループのどちらか一方でも仲間を集めた集合。
「A の仲間または B の仲間」のどちらかに入っていれば全員集合。

A ∪ B　＝　「A または B」
🌟 同じ例で考えてみよう
・A = 野球が好きな人のグループ
・B = サッカーが好きな人のグループ
A∪B（A または B）は 野球かサッカーの少なくとも一方が好きな人！
・野球だけ好きな人 → 入る ✓
・サッカーだけ好きな人 → 入る ✓
・両方好きな人 → 入る ✓
・どっちも好きじゃない人 → 入らない ✗
塗りつぶし部分が A∪B
（どっちか好きな人全員）
例題 3
A = { 1, 2, 3, 5, 6 }、B = { 3, 4, 5, 6, 7 } のとき、
（1）A∩B　（2）A∪B　を求めよ。
日本語で考えましょう
（1）A∩B：A の仲間でもあり B の仲間でもある人を探す
　　A の仲間 {1, 2, 3, 5, 6}　B の仲間 {3, 4, 5, 6, 7}
　　両方にいるのは → { 3, 5, 6 }

（2）A∪B：A か B のどちらかの仲間を全員集める
　　ただし「3」「5」「6」は両方にいるので、1回ずつ書く
　　→ { 1, 2, 3, 4, 5, 6, 7 }
💡 解き方のコツ
・A∩B：両方の中カッコを見比べて、両方にいる仲間（共通の数字）だけを書き出す
・A∪B：両方の仲間を全部書いて、同じ仲間は1個だけ残す

4．補集合 A とベン図

全体集合 U

考える範囲全体のグループを 全体集合 U といいます。
ベン図では 外側の四角 で表します。U は「仲間候補の全員」が入っているグループ。

補集合 A

U の中で、A の仲間に入っていない人を集めた集合を、Aの補集合といい A と書きます。
つまり「A の仲間じゃない人たち」のグループです。

🌟 身の回りの例で考えてみよう
クラス全員を U（全体）、納豆が好きな人を A とすると…
A は 納豆が嫌いな人のグループ！
（クラス全員から納豆好きの人を除いた残り）
Aの外側（塗りつぶし）が A
例題 4
全体集合 U = { 1, 2, 3, 4, 5, 6, 7, 8 }、A = { 2, 4, 6, 8 } のとき、A を求めよ。
日本語で考えましょう
U の仲間（候補全員）は { 1, 2, 3, 4, 5, 6, 7, 8 }
A の仲間は { 2, 4, 6, 8 }（偶数）
→ A の仲間ではない人を選ぶ → 残りは 奇数 { 1, 3, 5, 7 }
A = { 1, 3, 5, 7 }
💡 ポイント：補集合 A はそのまま単独で出るだけでなく、
次の A∩B や A∩B のような組み合わせでも出題されます（R7-2 で出題実績あり）。次の section で詳しく説明します。

5．A と他の記号の組み合わせ（重要）

⚠️ 生徒の質問が多いところです
ここはベン図と組み合わさるので「わからない」と感じる生徒が多い場所。
日本語に置き換えて考えるのがコツです。

A∩B（Aの外側、かつ、Bの中）

A∩B を日本語で考えましょう。

A∩B
　└ A（Aではない）　かつ　B（Bである）
　= 「Aではない、かつ、Bである」
　= 「Aの仲間じゃないけど、Bの仲間ではある人」

📊 ベン図でステップを追ってみよう

ステップ1：まず A を考える（Aの外側）
斜線部分が A（Aの外側全部・Bの一部も含む）
ステップ2：次に B を考える（Bの中）
斜線部分が B（Bの円の中全部・Aの一部とも重なる）
ステップ3：両方を満たすところ → A∩B
斜線部分が A∩B（Bの中だけど、Aには入っていない部分）
🌟 身の回りの例で考えてみよう
・A = 野球が好きな人のグループ
・B = サッカーが好きな人のグループ
A∩B は：
　「野球が好きじゃない、かつ、サッカーが好き」
　= サッカーだけが好きな人（野球は好きじゃない人）

A∩B（Aの中、かつ、Bの外側）

A∩B は A∩B の左右が入れ替わったバージョンです。同じように日本語で考えましょう。

A∩B
　└ A（Aである）　かつ　B（Bではない）
　= 「Aである、かつ、Bではない」
　= 「Aの仲間ではあるけど、Bの仲間ではない人」
斜線部分が A∩B（Aの中だけど、Bには入っていない部分）
🌟 身の回りの例で考えてみよう
・A = 野球が好きな人のグループ
・B = サッカーが好きな人のグループ
A∩B は：
　「野球が好き、かつ、サッカーが好きじゃない」
　= 野球だけが好きな人（サッカーは好きじゃない人）
📌 見分け方のコツ
ベン図で「片方の円の中にだけ斜線」がある問題：
・Aの中だけ斜線 → A∩B（A であり B ではない）
・Bの中だけ斜線 → A∩B（A ではなく B である）

覚え方：「中にある方が前、外にある方は上線（補集合）」

📌 まとめ

記号意味具体例
∈ 要素である
（仲間である）		 太郎 a はサッカー部 B の一員（仲間）
→ a ∈ B
⊂ / ⊃ 含まれる / 含む 4の倍数 A は 2の倍数 B に含まれる
→ A ⊂ B（A は B の部分集合）
A∩B 共通部分
（A かつ B）		 野球が好き A、サッカーが好き B
→ A∩B＝両方好き
A∪B 和集合
（A または B）		 ネコが好き A、犬が好き B
→ A∪B＝A と B のいずれかが好き
A 補集合
（A の外側）		 納豆が好きな人 A
→ A＝納豆が嫌いな人
∅ 空集合
（仲間が0人）		 赤たすき A ∩ 白たすき B
→ ∅（同時には付けられない）

この記号と意味さえ覚えれば、過去問の集合問題は7〜8割解けます。
