セットA　所属・包含（∈・∉・⊂・⊃）

記号の意味を判別する問題です。

A-1
A = { 1, 3, 5, 7, 9 } のとき、5 □ A に入る記号は？
✓ 解説 5はAの要素なので「∈（要素である）」。正解は ② ∈。
A-2
A = { 2, 4, 6, 8, 10 }、B = { 4, 8 } のとき、A □ B に入る記号は？
✓ 解説 Bの要素 4・8 はすべてAに含まれる → AはBを含む → A ⊃ B。正解は ④ ⊃。
A-3
A = { 1, 2, 3 }、B = { 1, 2, 3, 4, 5 } のとき、A □ B に入る記号は？
✓ 解説 Aの要素 1・2・3 はすべてBに含まれる → AはBに含まれる → A ⊂ B。正解は ③ ⊂。
A-4
A = { 1, 2, 3, 4, 5 } のとき、6 □ A に入る記号は？
✓ 解説 6はAの中にない → 「∉（要素ではない）」。正解は ① ∉。
セットA：0／4問正解

セットB　共通部分 A∩B

両方に共通する要素を取り出します。

B-1
A = { 1, 2, 3, 5, 6 }、B = { 3, 4, 5, 6, 7 } のとき、A∩B は？
✓ 解説 両方に含まれる要素は 3・5・6。正解は ③ { 3, 5, 6 }。
B-2
A = { 1, 2, 3, 5, 6 }、B = { 3, 6, 9 } のとき、A∩B は？
✓ 解説 両方に含まれる要素は 3・6。正解は ② { 3, 6 }。
B-3
A = { 1, 3, 5, 7, 9 }、B = { 2, 3, 6, 8 } のとき、A∩B の要素は？
✓ 解説 両方に含まれる要素は 3 のみ。正解は ③ 3。
B-4
Aを偶数全体の集合、Bを奇数全体の集合とするとき、A □ B = ∅（空集合）が成り立つ □ は？
✓ 解説 偶数と奇数に共通する数はない → A∩B＝∅（空集合）。正解は ④ ∩。
セットB：0／4問正解

セットC　和集合 A∪B

少なくとも一方にある要素を全部集めます。

C-1
A = { 1, 2, 4, 8 }、B = { 1, 2, 5, 10 } のとき、A∪B は？
✓ 解説 両方の要素を全部集めて、重複は1個だけ残す → { 1, 2, 4, 5, 8, 10 }。正解は ④。
C-2
A = { 2, 4, 6 }、B = { 1, 3, 5 } のとき、A∪B は？
✓ 解説 共通要素はないが、和集合は両方を合わせたもの → { 1, 2, 3, 4, 5, 6 }。正解は ③。
C-3
A = { 1, 2, 3 }、B = { 2, 3, 4, 5 } のとき、A∪B は？
✓ 解説 両方を合わせて、重複した 2・3 は1個だけにする → { 1, 2, 3, 4, 5 }。正解は ②。
C-4
U = { 1, 2, 3, 4, 5, 6 }、A = { 1, 2, 3 }、B = { 1, 3, 5 } のとき、{ 1, 3 } と等しい集合は？
✓ 解説 AとBに共通する要素は 1・3 → A∩B = { 1, 3 }。正解は ② A∩B。
セットC：0／4問正解

セットD　補集合・ベン図

全体集合の中で「Aに入っていない」要素を考えます。

D-1
U = { 1, 2, 3, 4, 5, 6, 7, 8 }、A = { 2, 4, 6, 8 } のとき、A は？
✓ 解説 UからAの要素を除く → { 1, 3, 5, 7 }（奇数）。正解は ③。
D-2
U = { 1, 2, 3, 4, 5 }、A = { 1, 3, 5 } のとき、A は？
✓ 解説 UからAの要素を除く → { 2, 4 }。正解は ②。
D-3
下のベン図の塗りつぶし部分を表す集合は？
✓ 解説 AとBが重なっている部分（レンズ型）のみ塗られているので、A∩B。正解は ③。
D-4
下のベン図の塗りつぶし部分を表す集合は？
✓ 解説 AとBの両方の円全体が塗られているので、A∪B。正解は ②。
セットD：0／4問正解

セットE　空集合 ∅

共通の仲間が1人もいない＝空集合。R6-2 で出題された重要パターン。

E-1
A を偶数全体の集合、B を奇数全体の集合とするとき、
「A □ B = ∅」が成り立つ。□ に入る記号はどれ？
✓ 解説 偶数と奇数に共通する数はない（同時に偶数で奇数の数はない）。
→ A∩B＝∅（空集合）。正解は ④ ∩。
E-2
A を正の整数全体の集合、B を負の整数全体の集合とするとき、
「A □ B = ∅」が成り立つ。□ に入る記号はどれ？
✓ 解説 正の整数（1、2、3…）と負の整数（-1、-2、-3…）に共通する数はない。
→ A∩B＝∅。正解は ④ ∩。
E-3
運動会で、A を赤いたすきをした人のグループ、B を白いたすきをした人のグループとする。
このとき、A∩B はどうなる？
✓ 解説 1人が同時に赤と白の両方のたすきをすることはできない。
→ 共通の仲間は0人 → A∩B＝∅。正解は ②。
E-4
A を3の倍数全体の集合、B を5の倍数全体の集合とするとき、A∩B は…
✓ 解説 3でも5でも割れる数 → 15、30、45…（15の倍数）
共通の仲間が無限にいるので、空集合ではない。
→ A∩B＝15の倍数全体。正解は ②。
💡 注意：「共通の数がない」だけが空集合。少しでも共通すれば空集合ではない。
セットE：0／4問正解

セットF　記号からベン図を選ぶ

記号の意味を理解しているか、ベン図を選んで確認しよう。

F-1
集合「A∩B」を表すベン図はどれ？
✓ 解説 A∩B は「A かつ B」＝ AとBの両方の仲間。
2つの円が重なっているレンズ部分だけ斜線になっている①が正解。
F-2
集合「A∩B」を表すベン図はどれ？
✓ 解説：日本語で考えましょう A∩B は「A であり、かつ B ではない」
→ A の中にあって、B には入っていない部分
→ Aの中だけ斜線がある ③ が正解。
F-3
集合「A∩B」を表すベン図はどれ？
✓ 解説：日本語で考えましょう A∩B は「A ではなく、かつ B である」
→ A の外側にあって、B の中に入っている部分
→ Bの中だけ斜線がある ④ が正解。
セットF：0／3問正解
