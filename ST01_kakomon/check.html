ST01　集合　実戦テスト

過去問パターン 厳選5問　満点で合格

📝 実戦テストの進め方

過去問演習で学んだパターンを、別の数値で確認するテストです。本番のつもりで5問解いてから「採点する」を押してください。満点で合格です。

R7-2型問1
全体集合 U の部分集合 A、B について、下の図の斜線部分を表す集合はどれか。
R6-2型問2
A を正の整数全体の集合、B を負の整数全体の集合とするとき、
「A □ B = ∅」が成り立つ。□ に入る記号はどれか。
R6-1型問3
A = { 1, 3, 5, 7, 9 }、B = { 3, 5 } のとき、A と B の関係は A □ B である。□ に入る記号はどれか。
R5-1型問4
A = { 2, 3, 5, 7, 11 }、B = { 1, 3, 5, 7, 9 } のとき、次のうち正しいものはどれか。
R3-2型問5
U = { 1, 2, 3, 4, 5, 6 } を全体集合とする。
A = { 2, 4, 6 }、B = { 1, 2, 4, 5 } のとき、{ 2, 4 } と等しい集合はどれか。
