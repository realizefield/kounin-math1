ST01　集合　過去問演習

R1〜R7の高認過去問 全8問
📚 過去問演習について
集合の問題は高認数学で毎年1問出題されており、40点合格には必ず正解したい単元です。新しい年度から順番に解いて、出題パターンに慣れましょう。

セット②R5・R4・R3
セット③R2・R1

セット①　最新2年（R7・R6）

最新の出題傾向を押さえる重要セットです。

R7-2問1
全体集合 U の部分集合 A、B について、右の図の斜線部分を表す集合は次のうちどれか。
✓ 解説 斜線部分は Bの中 にあり、かつ Aの外側。
→ 「Aではない（A）」かつ「Bである」 → A∩B。正解は ④。
💡 戦略：斜線がどの円の中にあるかで「A」「B」を確定し、
外側に出ている場合は補集合（A、B）と考えるとミスが減ります。
R6-2問2
A を偶数全体の集合、B を奇数全体の集合とするとき、
「A □ B = ∅」が成り立つ。□ に入る記号はどれか。
✓ 解説 偶数と奇数に共通する数はない（同時に偶数かつ奇数の数は存在しない）。
→ A∩B＝∅（空集合）。正解は ④ ∩。
💡 ポイント：∅（空集合）は「要素が1つもない集合」のこと。
共通部分（∩）が空になるのは、2つの集合に重なりがないとき。
R6-1問3
集合 A、B について、A = { 2, 4, 6, 8, 10 }、B = { 4, 8 } のとき、
集合 A と集合 B の関係は A □ B である。□ に入る記号はどれか。
✓ 解説 Bの要素 4・8 はすべてAに含まれる → AはBを含む → A ⊃ B。正解は ④ ⊃。
💡 戦略：⊂ や ⊃ の開いた方が大きい集合。
A（5個）⊃ B（2個）→ Aの方が大きいので開いた方がA側。
セット①：0／3問正解

セット②　過去5年（R5・R4・R3）

包含関係・共通部分・部分集合の典型問題です。

R5-1問4
A = { 1, 2, 4, 7, 8, 9 }、B = { 1, 4, 6, 7, 9 } のとき、次のうち正しいものはどれか。
✓ 解説 A∩B（両方にある要素）：1、4、7、9 → { 1, 4, 7, 9 }
A∪B（少なくとも一方にある要素）：1、2、4、6、7、8、9 → { 1, 2, 4, 6, 7, 8, 9 }
正解は ②。
💡 戦略：選択肢に A∩B と A∪B が混ざっている問題は、
まず両方を計算してから選択肢と照らし合わせるのがミスを防ぐコツ。
R4-1問5
36 の正の約数全体の集合の部分集合になっているものはどれか。
✓ 解説 まず36の正の約数を全部書き出します。
36 ÷ 1 = 36、36 ÷ 2 = 18、36 ÷ 3 = 12、36 ÷ 4 = 9、36 ÷ 6 = 6
→ 36の正の約数 = { 1, 2, 3, 4, 6, 9, 12, 18, 36 }

各選択肢を確認：
① { 1, 2, 4, 8 } → 8 は36の約数ではない（含まれない）
② { 1, 3, 9, 27 } → 27 は36の約数ではない
③ { 4, 9, 18 } → すべて36の約数（4も9も18も含まれる）✓
④ { 12, 24 } → 24 は36の約数ではない
正解は ③ { 4, 9, 18 }。
💡 戦略：「部分集合」＝「全要素が元の集合に含まれる」。
1つでも含まれない要素があれば、その選択肢は不正解。
R3-2問6
U = { 1, 2, 3, 4, 5, 6 } を全体集合とする。
A = { 1, 2, 3 }、B = { 1, 3, 5 } のとき、{ 1, 3 } と等しい集合はどれか。
✓ 解説 A∩B（両方にある要素）= { 1, 3 } ← これが正解と一致！
A∪B = { 1, 2, 3, 5 }
正解は ② A∩B。
💡 戦略：複雑そうに見えても、まず A∩B と A∪B を計算。
A（補集合）まで使う問題は意外と少なく、まずは基本2つで判定。
セット②：0／3問正解

セット③　旧年度（R2・R1）

共通部分・和集合の基本問題で総仕上げ。

R2-1問7
A = { 1, 2, 3, 5, 6 }、B = { 3, 4, 5, 6, 7 } のとき、
A∩B の要素を書き並べて表すとどうなるか。
✓ 解説 両方に含まれる要素：3、5、6 → A∩B = { 3, 5, 6 }。正解は ③。
💡 ポイント：A∩Bは「両方の中カッコを見比べて、共通の数字だけを書く」だけ。
指で順番に数字をなぞって確認すると確実です。
R1-1問8
A = { 1, 2, 4, 8 }、B = { 1, 2, 5, 10 } のとき、A∪B と等しい集合はどれか。
✓ 解説 両方の要素を全部集めて、重複は1個だけ：
A の要素：1、2、4、8　Bの要素：1、2、5、10
→ A∪B = { 1, 2, 4, 5, 8, 10 }。正解は ④。
💡 ポイント：和集合は「両方を合わせて、ダブった数字は1個だけ」。
書く順番は小さい順にすると見やすい。
セット③：0／2問正解
