📌 2次不等式とは？

たとえば のように、2次式に不等号がついたものを「2次不等式」といいます。

「この式が 0 より大きくなる（または小さくなる）x の範囲はどこか？」を求める問題です。

グラフで考えるのが一番わかりやすい方法です。
放物線が x 軸より「上」にある部分と「下」にある部分を見れば、答えがわかります。

青の部分（y < 0）→ x軸より下　　緑の部分（y > 0）→ x軸より上

🔑 「内側」と「外側」で覚えましょう

上向き放物線（a > 0）で、x軸との交点が のとき：

y < 0（x軸より下）

「内側」

y > 0（x軸より上）

「外側」

💡 覚え方

< 0（x軸より下）→ 「内側」→
> 0（x軸より上）→ 「外側」→

≦ や ≧ のときは、等号を含めるだけです（α、β もふくむ）。

✅ 解く手順

1
因数分解して x 軸との交点（根）α、β を求めます。
2
不等号の向きを確認します。
< 0 または ≦ 0 なら「内側」、> 0 または ≧ 0 なら「外側」
3
答えを書きます。
内側：　外側：
⚠️ 係数が負（a < 0）のとき
まず両辺を −1 倍して a > 0 にしてから考えます。
このとき不等号の向きが逆になることに注意してください。
