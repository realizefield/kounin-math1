セットA　座標の読み方

（χ, y）の形を正しく読んで答えましょう。

A-1
点 A(3, 2) の正しい位置は？
✓ 解説 A(3, 2) → 左がχ、右がy の順。χ＝3（右に3）、y＝2（上に2）。第1象限の点。
A-2
点 B(－2, 3) は何象限？
✓ 解説 χ＝－2（左）、y＝3（上） → χ－・y＋ → 第2象限（左上）
A-3
点 C(1, 0) はどこ？
✓ 解説 y＝0 → χ軸上の点。（χ軸はy＝0の直線）
A-4
正しいのはどれ？
✓ 解説 順番が違うと別の点。(0, 0)は原点（象限には属さない）。χは左右方向。
セットA：0／4問正解

セットB　二次関数の向き・形

a の符号と大きさからグラフの特徴を答えましょう。

B-1
二次関数 y = 4χ² のグラフの向きは？
✓ 解説 a ＝ 4 ＞ 0（プラス）→ 下に凸（U字型）
B-2
二次関数 y = －½χ² のグラフの向きは？
✓ 解説 a ＝ －½ ＜ 0（マイナス）→ 上に凸（山型）
B-3
y＝3χ² と y＝½χ²、グラフが細いのはどちら？
✓ 解説 a の数字が大きいほど細くなる。3 ＞ ½ なので y＝3χ² の方が細い。
B-4
y＝aχ²（a≠0）の頂点の座標はどこ？
✓ 解説 y＝aχ²では χ＝0 のとき y＝0。頂点は常に原点 (0, 0)。
セットB：0／4問正解

セットC　総合問題

座標と二次関数の知識を組み合わせて答えましょう。

C-1
点 D(－3, －4) は何象限？
✓ 解説 χ－、y－ → 第3象限（左下）
C-2
二次関数 y = －3χ² の頂点の座標は？
✓ 解説 y＝aχ²の形では頂点は常に原点 (0, 0)。a＝－3（上に凸）でも頂点は (0, 0)。
C-3
y が x の二次関数であるものはどれ？
✓ 解説 二次関数は「x²の項がある」関数。④ y＝2x²＋1 → x²あり → 二次関数。
C-4
y＝aχ²でaが1→5に変わるとグラフはどう変わる？
✓ 解説 a の数字が大きくなる → グラフは細くなる。向き・頂点は変わらない。
セットC：0／4問正解
