① EF11 との違い
📌 真ん中の係数がマイナスの場合
EF11では「両プラス」型（$2x^2 + 5x + 3$ など）を学びました。
今度は $6x^2 - 7x + 2$ のように 真ん中の係数 $b$ がマイナス，
かつ 定数項 $c$ がプラス の場合を扱います。
📌 公式と符号
$ax^2 - bx + c$（$b > 0, c > 0$）
→ $(\bigcirc x - \square)(\bigcirc x - \square)$ — 両方マイナス
② なぜ両方マイナスになるの？
📌 符号のしくみ
EF06-2（係数1の両マイナス）と同じ理由：
・かけて：$(-A) \times (-B) = +AB$ → 定数項プラス ✓
・たして：$(-A) + (-B) = -(A+B)$ → 真ん中の係数マイナス ✓
だから 「定数項＋ かつ 係数−」 なら，両方マイナス 確定！
⚠️ 符号判定の鉄則
定数項 $c$ ＋ ＋ 真ん中の係数 $b$ −　→　たすき掛けは両方マイナス
つまり $(\,?\,x - ?)(\,?\,x - ?)$ の形になる！
③ 例題：$6x^2 - 7x + 2$ を因数分解する
考え方
符号確認
定数項 $+2$，係数 $-7$ → 両方マイナス 確定
予想
$6x^2$ → $(6x \cdots)(x \cdots)$ または $(3x \cdots)(2x \cdots)$
予想
$+2$ → $(\cdots -1)(\cdots -2)$（両方マイナス）
パターン①：$(6x-1)(x-2)$？
たすと $-13x$ → 真ん中の $-7x$ と不一致 ✗
パターン②：$(3x-2)(2x-1)$？
たすと $-7x$ → 一致！ こっちが正解！
$6x^2 - 7x + 2 = (3x-2)(2x-1)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$3x$ と $-1$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$-2$ と $2x$ を 隣り合う内側 に置く
こうして $(3x-2)(2x-1)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
💡 「両プラス」と「両マイナス」の見分け方
定数項 $c$ が プラス なら → 両方プラス（EF11）か 両方マイナス（EF12）
係数 $b$ が プラス → 両プラス（EF11）
係数 $b$ が マイナス → 両マイナス（EF12）
④ 解き方の手順
1
符号確認　定数項 $+$，係数 $-$ → 両マイナス
2
$x^2$ の係数を分解　例：$6 = 3 \times 2$
3
定数項を分解　例：$2 = 1 \times 2$（両方マイナスをつける）
4
たすき掛け　たして $b$（マイナス）になる組み合わせを探す
⑤ もう一つの例：$5x^2 - 36x + 7$
考え方
符号確認
定数項 $+7$，係数 $-36$ → 両マイナス
予想
$5$ は素数 → $(5x \cdots)(x \cdots)$，$7$ も素数 → $(\cdots -1)(\cdots -7)$ など
$(5x-1)(x-7)$？
たすと $-36x$ → 一致！
$5x^2 - 36x + 7 = (5x-1)(x-7)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$5x$ と $-7$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$-1$ と $1x$ を 隣り合う内側 に置く
こうして $(5x-1)(x-7)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
⑥ EF11 と EF12 の比較
EF11（両プラス）：定数項＋・係数＋
$2x^2 + 5x + 3 = (2x+3)(x+1)$
たすき掛けは 両方プラス
EF12（両マイナス）：定数項＋・係数−
$6x^2 - 7x + 2 = (3x-2)(2x-1)$
たすき掛けは 両方マイナス
両マイナス型は，計算過程の符号ミスに 特に注意！
たすき掛けの数字を すべてマイナスで書く のを忘れずに。
「定数項＋」だけで 両プラス／両マイナス が決まる訳ではない！
必ず 係数の符号 も確認すること。
📌 まとめ
  • EF12：$ax^2 - bx + c$（$b>0$, $c>0$）の因数分解
  • 定数項＋ かつ 係数− → 両方マイナス
  • 解法：たすき掛けの数字を すべてマイナス にして組み合わせを探す
  • $(\,?\,x - ?)(\,?\,x - ?)$ の形になる
  • 計算結果も すべてマイナス なので，たし算は 絶対値の和にマイナスをつける
  • 次は EF13（符号が逆）— 定数項マイナスのパターン！
