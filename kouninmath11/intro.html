① EF06 との違い
📌 $x^2$ の係数が1ではない場合
EF06 では $x^2 + bx + c$（$x^2$の係数が1）の因数分解を学びました。
今度は $2x^2 + 5x + 3$ のように $x^2$ の係数が1ではない 場合の因数分解を学びます。
こちらも高認の 頻出問題 です！
📌 公式（EF10の逆）
$acx^2 + (ad+bc)x + bd = (ax+b)(cx+d)$
📌 「たすき掛け」とは？
EF10で学んだ 「外×外＋内×内」 の 逆操作 をします。
具体的には，たすき掛け（X字に掛け算する図） を使って
$ax+b$ と $cx+d$ の組み合わせを見つけます。
② 例題：$2x^2 + 5x + 3$ を因数分解する
考え方
予想
$2x^2$ なので $(2x \cdots)(x \cdots)$ になる
予想
$+3$ なので $(\cdots +1)(\cdots +3)$ または $(\cdots +3)(\cdots +1)$ になる
？
どっちの組み合わせが正しいか，たすき掛け で確かめよう！
パターン①：$(2x+1)(x+3)$ — 確認
たすと $7x$ → 真ん中の $5x$ にならない ✗
パターン②：$(2x+3)(x+1)$ — 確認
たすと $5x$ → 真ん中の $5x$ と一致 ✓ こっちが正解！
$2x^2 + 5x + 3 = (2x+3)(x+1)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$2x$ と $1$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$3$ と $1x$ を 隣り合う内側 に置く
こうして $(2x+3)(1x+1) = (2x+3)(x+1)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
💡 たすき掛けのポイント
① 左の縦：$x^2$ の係数の分解（例：$2 = 2 \times 1$）
② 右の縦：定数項の分解（例：$3 = 1 \times 3$ または $3 \times 1$）
③ 対角線で 掛けて → たして，真ん中の係数 $b$ になればOK！
③ 解き方の手順
1
$x^2$ の係数を分解　例：$2 = 2 \times 1$
2
定数項を分解　例：$3 = 1 \times 3$（順番違いも考える）
3
たすき掛け　対角線で掛けて，たした結果が 真ん中の係数 $b$ になる組み合わせを探す
4
$(ax+b)(cx+d)$ の形で書く（横の組み合わせ）
「両プラス」型 では，定数項 $bd$ も真ん中の係数 $b$ も 両方プラス なので，
たすき掛けの数字は すべてプラス。マイナス符号は出てきません！
④ 別の例：$3x^2 + 7x + 2$
考え方
予想
$3x^2$ なので $(3x \cdots)(x \cdots)$
予想
$+2$ なので $(\cdots +1)(\cdots +2)$ または $(\cdots +2)(\cdots +1)$
確認
どっちか，たすき掛けで確かめる
パターン①：$(3x+2)(x+1)$ — 確認
たすと $5x$ → 真ん中は $7x$ なので不一致 ✗
パターン②：$(3x+1)(x+2)$ — 確認
たすと $7x$ → 真ん中の $7x$ と一致 ✓ 正解！
$3x^2 + 7x + 2 = (3x+1)(x+2)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$3x$ と $+2$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$+1$ と $1x$ を 隣り合う内側 に置く
こうして $(3x+1)(x+2)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
⑤ 検算（展開して元に戻るか）
📌 不安なときは「展開で検算」
たすき掛けで答えを出したあとは，EF10 の展開公式 で元に戻るか確認すると安心：
$(2x+3)(x+1) = 2x^2 + 2x + 3x + 3 = 2x^2 + 5x + 3$ ✓
たすき掛けは「慣れ」がモノを言う！
最初は時間がかかっても，何問か解くうちにパッと組み合わせが見えるようになる。
📌 まとめ
  • EF11：$ax^2 + bx + c$ の因数分解（両プラス型）
  • EF06と違って，$x^2$ の係数が1ではない
  • 解法：たすき掛け（X字の図）で組み合わせを見つける
  • 手順：① $a$を分解 → ② $c$を分解 → ③ たすき掛けで $b$ を確認
  • 両プラス型は すべてプラス なので，符号を気にしなくてOK
  • 不安なときは 展開で検算（EF10の逆）
