IN03 不等式の解き方②（応用変形）

分数・小数・両辺に文字がある場合の解き方

① IN02の復習：基本の解き方

IN02では、次のような形の不等式を解く方法を学びました。

$2x + 5 \leqq 11$ → $2x \leqq 6$ → $x \leqq 3$

基本の流れは「移項する → 両辺で割る」でした。
負の数で割るときは不等号の向きが反転することも学びましたね。

② IN03で学ぶ「応用変形」とは？

高認試験では、もう少し複雑な形の不等式が出題されます。たとえば──

・両辺に文字 $x$ がある：$\quad 7 + 2x \leqq 5x - 2$

・分数を含む：$\quad 2 - x \geqq \dfrac{x-1}{3}$

・小数を含む：$\quad 0.6x + 1.3 > 2.5 + x$

これらは 「整理してから IN02 の形に持ち込む」 のが基本方針です。

③ 解き方の流れ（4ステップ）

  1. カッコがあれば外す（分配法則）
  2. 分数・小数があれば、両辺に同じ数をかけて整数にする
  3. 文字 $x$ は左に、数字は右に移項する
  4. 両辺を $x$ の係数で割る（負の数で割ったら不等号反転！）

④ 重要ポイント

★ココが大事①：両辺に文字がある場合

文字 $x$ は左、数字は右に移動させましょう。

例：$7 + 2x \leqq 5x - 2$
→ 文字 $5x$ を左へ、数字 $7$ を右へ移項
→ $2x - 5x \leqq -2 - 7$
→ $-3x \leqq -9$（あとは IN02 と同じ）

★ココが大事②：分数を含む場合

両辺に「分母の数」をかけて、分数をなくしましょう。

例：$2 - x \geqq \dfrac{x-1}{3}$
→ 両辺に $3$ をかける
→ $3(2-x) \geqq x - 1$
→ $6 - 3x \geqq x - 1$（あとは整理）

★ココが大事③：小数を含む場合

両辺に $10$（または $100$）をかけて、整数にしましょう。

例：$0.6x + 1.3 > 2.5 + x$
→ 両辺に $10$ をかける
→ $6x + 13 > 25 + 10x$（あとは整理）

⑤ ⚠落とし穴に注意

⚠ 落とし穴①：かけ算するときは「両辺すべて」にかける

分数や小数をなくすためにかけ算するときは、左辺・右辺のすべての項にかけるのを忘れずに。

$2 - x \geqq \dfrac{x-1}{3}$ の両辺に $3$ をかけるとき
✗ $2 - x \geqq x - 1$（左辺にかけ忘れ）
✓ $3(2-x) \geqq x - 1$ → $6 - 3x \geqq x - 1$

⚠ 落とし穴②：負の数で割るときは不等号反転

整理した結果、$x$ の係数が負になったら、両辺を割るときに 不等号の向きを反転 させましょう。

$-3x \leqq -9$ → 両辺を $-3$ で割ると $x \geqq 3$（向き反転！）

⑥ 不等式の性質（応用問題）

高認では「$a < b$ のとき、次のうち正しい不等式はどれか」という性質を問う4択問題もよく出ます。

覚えておくこと：

操作不等号の向き
両辺に同じ数を足す・引く変わらない
両辺に正の数をかける・割る変わらない
両辺に負の数をかける・割る反転する

$a < b$ のとき、$-a$ と $-b$ ではどちらが大きい？　→ $-a > -b$（向きが反転）

⑦ この単元のゴール

🎯 できるようになること

  • 両辺に文字がある不等式を解ける
  • 分数を含む不等式を、両辺に分母をかけて整数化して解ける
  • 小数を含む不等式を、両辺に10をかけて整数化して解ける
  • $a < b$ のとき、正しい不等式を選べる（性質判別）高認毎年出題
