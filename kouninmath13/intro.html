① たすき掛けの最終形
📌 定数項がマイナスの場合
EF11（両プラス）, EF12（両マイナス）と来て，最後は 定数項がマイナス の場合：
例：$3x^2 + 5x - 2$，$5x^2 + 7x - 6$ など。
定数項マイナス → かけて−（マイナス）→ 2数の符号が逆 になります。
高認では このパターンが最頻出！
📌 公式と符号
$ax^2 \pm bx - c$　→　$(\bigcirc x + \square)(\bigcirc x - \square)$
※ 2数は 片方プラス，もう片方マイナス
② なぜ符号が逆になるの？
📌 EF06-3と同じしくみ
2つの数を $+A$ と $-B$（符号が逆）とすると：
・かけて：$(+A) \times (-B) = -AB$ → 定数項マイナス ✓
・たして：$A + (-B) = A - B$ → 真ん中の係数 $b$ は プラスでもマイナスでも両方OK
⚠️ 符号判定の鉄則
定数項 $c$ −（マイナス）　→　たすき掛けは 片方+，もう片方−
係数 $b$ の符号は +でも−でもどちらでもよい
③ 例題：$5x^2 - 34x - 7$
考え方
符号確認
定数項 $-7$ → 符号が逆，係数 $-34$
予想
$5x^2$ → $(5x \cdots)(x \cdots)$，$-7$ → かけて $-7$ → $+1, -7$ または $-1, +7$ の組
$(5x+1)(x-7)$？
たすと $-34x$ → 一致！
$5x^2 - 34x - 7 = (5x+1)(x-7)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$5x$ と $-7$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$+1$ と $1x$ を 隣り合う内側 に置く
こうして $(5x+1)(x-7)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
💡 「符号が逆」型のコツ
① まず 絶対値で組み合わせを試す（例：$1 \times 7$，$7 \times 1$）
② 次に どちらをプラス，どちらをマイナス にするか試す
③ たして真ん中の係数 $b$ になる組み合わせを見つける
④ 解き方の手順
1
符号確認　定数項 $-c$ → 符号が逆（片方+，片方-）
2
$x^2$ の係数を分解　例：$5 = 5 \times 1$
3
定数項の絶対値を分解　例：$|-7| = 7 = 1 \times 7$
4
たすき掛け × 符号　$+, -$ の振り方を変えて，たして $b$ になる組を探す
「符号が逆」型は たすき掛けで一番間違えやすい！
$(5x+1)(x-7)$ と $(5x-1)(x+7)$ では結果が違うので，慎重に符号を試す こと。
⑤ もう一つの例：$3x^2 + 5x - 2$
考え方
符号確認
定数項 $-2$ → 符号が逆，係数 $+5$
予想
$3 = 3 \times 1$，$2 = 1 \times 2$ または $2 \times 1$
パターン①：$(3x+2)(x-1)$？
たすと $-1x$ → 不一致 ✗
パターン②：$(3x-1)(x+2)$？
たすと $+5x$ → 一致！
$3x^2 + 5x - 2 = (3x-1)(x+2)$
🔑 「✓」が出たあと，どうやって答えの形に？
📌 「外と外」「内と内」の置き方：
・赤の弧（外と外）：$3x$ と $+2$ を 同じ括弧の両端 に置く
・青の弧（内と内）：$-1$ と $1x$ を 隣り合う内側 に置く
こうして $(3x-1)(x+2)$ になる！
💡 これは EF10 の「外×外＋内×内」の逆操作！　展開で学んだ仕組みを 巻き戻している だけ。
⑥ EF11・EF12・EF13 の比較
EF11（両プラス）：定数項+・係数+
$2x^2 + 5x + 3 = (2x+3)(x+1)$
たすき掛け数字 すべてプラス
EF12（両マイナス）：定数項+・係数−
$6x^2 - 7x + 2 = (3x-2)(2x-1)$
たすき掛け数字 すべてマイナス
EF13（符号が逆）：定数項−
$3x^2 + 5x - 2 = (3x-1)(x+2)$
たすき掛け数字 +/−が混在
3パターンの判別は 定数項と係数の符号 で決まる！
・定数項+，係数+ → EF11（両プラス）
・定数項+，係数− → EF12（両マイナス）
・定数項− → EF13（符号が逆）
📌 まとめ
  • EF13：$ax^2 \pm bx - c$ の因数分解（符号が逆）
  • 定数項 − → 2数の符号が逆（片方+，片方−）
  • $(\bigcirc x + \square)(\bigcirc x - \square)$ の形になる
  • たすき掛けで 符号の振り方を試す
  • $(5x+1)(x-7)$ と $(5x-1)(x+7)$ は別物 → 慎重に確認
