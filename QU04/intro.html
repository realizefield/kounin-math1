QU04　二次不等式

グラフを使って不等式を解く
① 解説
② 演習
③ 確認

1．χ軸との共有点を求める

二次関数のグラフと χ軸の交点を求めるには、y＝0 として方程式を解くだけです。

✅ 手順

y＝f(χ) のグラフと χ軸の交点を求める
→ f(χ) ＝ 0 を解く（因数分解）
→ 解が χ＝α、β → 交点は (α, 0) と (β, 0)
📌 例題　y＝χ²＋χ－6 とχ軸の共有点を求めよ
χ²＋χ－6 ＝ 0
(χ＋3)(χ－2) ＝ 0
χ ＝ －3、2
→ 共有点は (－3, 0) と (2, 0)
📌 例題　y＝2χ²＋5χ－3 とχ軸の共有点を求めよ
2χ²＋5χ－3 ＝ 0
(2χ－1)(χ＋3) ＝ 0
χ ＝ 12、－3
→ 共有点は (－3, 0) と (12, 0)

2．二次不等式とグラフの関係

二次不等式はグラフで考えると解きやすいです。

💡 グラフと不等式の関係
y ＞ 0 → グラフが χ軸より上 にある部分の χ の範囲
y ＜ 0 → グラフが χ軸より下 にある部分の χ の範囲
y ＞ 0 の範囲
χ＜α または χ＞β（外側）
y ＜ 0 の範囲
α＜χ＜β（内側）

✅ 覚え方

下に凸（a＞0）のグラフで α＜β のとき：

＞ 0（χ軸より上）→ 外側：χ＜α または χ＞β
＜ 0（χ軸より下）→ 内側：α＜χ＜β

≧、≦ の場合は α、β を含む（等号あり）

3．二次不等式を解く手順

1
右辺を0にする（移項してまとめる）
2
左辺を因数分解して α、β を求める（α＜β）
3
グラフの向き（aの符号）を確認して内側か外側か判断
4
答えを書く

例題①：＞0（外側）

χ²－5χ＋4 ＞ 0 を解け
χ²－5χ＋4 ＝ (χ－1)(χ－4) ＝ 0← まず＝0を解く
χ ＝ 1、4
a＝1＞0 → 下に凸 → ＞0 なので 外側
答え：χ＜1 または χ＞4

例題②：＜0（内側）

χ²－5χ＋4 ＜ 0 を解け
同様に χ＝1、4
a＞0 → 下に凸 → ＜0 なので 内側
答え：1＜χ＜4

例題③：移項が必要な場合

5χ²－6χ＋2 ≦ 2χ²＋5χ－4 を解け
5χ²－2χ²－6χ－5χ＋2＋4 ≦ 0 ← 右辺を0にする
3χ²－11χ＋6 ≦ 0
(3χ－2)(χ－3) ≦ 0
χ ＝ 23、3
a＞0 → ≦0 → 内側（等号含む）
答え：23 ≦ χ ≦ 3
⚠ 右辺を必ず 0 にしてから解く！
左辺と右辺に式がある場合は、必ず移項して右辺を0にしてから因数分解します。
例：(χ－1)(χ＋2) ≧ 0 → そのまま解ける
例：5χ²－6χ＋2 ≦ 2χ²＋5χ－4 → まず移項！

📋 まとめ

不等式グラフのイメージ答えの形
f(χ) ＞ 0χ軸より上（a＞0）χ＜α または χ＞β（外側）
f(χ) ＜ 0χ軸より下（a＞0）α＜χ＜β（内側）
f(χ) ≧ 0χ軸以上（a＞0）χ≦α または χ≧β（外側・等号含む）
f(χ) ≦ 0χ軸以下（a＞0）α≦χ≦β（内側・等号含む）
キーワード：＞0・≧0 → 外側　／　＜0・≦0 → 内側（a＞0の場合）
