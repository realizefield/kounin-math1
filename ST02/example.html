📝 例題1（テキストp.◯）

次の命題は真か偽か答えなさい。判定したら下の選択肢をタップしてください。

例題 1-(1)
「χ2＝4 ならば χ＝2 である」
この命題は真か偽か。
✓ 解説 χ2＝4 の解を求める：
χ2＝4
χ＝±2　（χ＝2 と χ＝－2 の2つ）
反例：χ＝－2 もχ2＝4 を満たすけど、χ＝2 にはならない。
解はχ＝2 だけではないので、命題は 偽
例題 1-(2)
「χ2＝2χ ならば χ＝0 である」
この命題は真か偽か。
✓ 解説 χ2＝2χ の解を求める：
χ2－2χ＝0
χ(χ－2)＝0
χ＝0、χ＝2
反例：χ＝2 もχ2＝2χ を満たすけど、χ＝0 ではない。
解はχ＝0 だけではないので、命題は 偽
例題 1-(3)
「a＞0、b＞0 ならば ab＞0 である」
この命題は真か偽か。
✓ 解説 正の数どうしの積は必ず正の数になります。
例：a＝2、b＝3 → ab＝6＞0 ✓
　 a＝0.5、b＝10 → ab＝5＞0 ✓
反例を探しても見つからない（aもbも正なら、abは必ず正）。
だから命題は 真

⚠️ 例題2　ここが難しい！

命題が苦手な生徒が特につまずきやすい3つのパターンを練習しましょう。

例題 2-(1) 逆向きパターン
「χ＝3 ならば χ2＝9 である」
この命題は真か偽か。
✓ 解説：例題1-(1)と比べてみよう 例題1-(1)は「χ2＝4 ならば χ＝2」で偽でしたね。
今回はその逆向きの命題です。
χ＝3 を χ2 に代入すると：
χ2＝32＝9 ✓
χ＝3 なら必ず χ2＝9 になる。反例なし。
だから命題は 真
💡 大事なポイント
・χ2＝9 ならば χ＝3 → 偽（χ＝－3もあるから）
・χ＝3 ならば χ2＝9 → 真（1方向だから確実）
逆向きにすると真偽が変わることがある！
例題 2-(2) 正負の積
「ab＞0 ならば a＞0、b＞0 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう ab＞0（積がプラス）になるのは、a と b が同じ符号のとき。
・(プラス)×(プラス)＝プラス　→ a＞0, b＞0 ✓
・(マイナス)×(マイナス)＝プラス　→ a＜0, b＜0 ✓
・(プラス)×(マイナス)＝マイナス　×
・(マイナス)×(プラス)＝マイナス　×
反例：a＝-2、b＝-3 のとき ab＝6＞0 だが、a＞0 でも b＞0 でもない！
反例があるので命題は 偽
💡 正負の積の4パターンを覚えよう
・a＞0、b＞0 → ab＞0（プラス）
・a＜0、b＜0 → ab＞0（プラス）※マイナス×マイナス＝プラス
・a＞0、b＜0 → ab＜0（マイナス）
・a＜0、b＞0 → ab＜0（マイナス）
例題 2-(3) 多解パターン
「χ2－3χ＝0 ならば χ＝3 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう χ2－3χ＝0 を解いてみます：
χ2－3χ＝0
χ(χ－3)＝0　（χ でくくる）
χ＝0、χ＝3
解は χ＝0 と χ＝3 の2つ。
反例：χ＝0 も χ2－3χ＝0 を満たすけど、χ＝3 ではない！
反例があるので命題は 偽
💡 大事なポイント
・χ2－3χ＝0 ならば χ＝3 → 偽（χ＝0 も解だから）
・χ＝3 ならば χ2－3χ＝0 → 真（代入すれば確認できる）
2次方程式は解が2つあることが多い→ 1つしか書いてないと偽になりがち！
