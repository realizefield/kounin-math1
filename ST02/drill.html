セットA　テキスト練習1

テキストの練習1の4問です。真か偽かを判定してください。

A-1
「a×b＞0 ならば、a＞0、b＞0 である」
この命題は真か偽か。
✓ 解説 反例：a＝－2、b＝－1 のとき、ab＝(－2)×(－1)＝2＞0 となるが、a＞0 でも b＞0 でもない。
（マイナス × マイナス ＝ プラス になる場合がある）
反例があるので 偽
A-2
「2つの辺の長さが等しい三角形は正三角形である」
この命題は真か偽か。
✓ 解説 反例：2辺だけ等しい三角形（二等辺三角形）はたくさんある。
例えば、辺の長さが 5, 5, 3 の三角形は二等辺三角形だが、正三角形ではない。
→ 正三角形は二等辺三角形の一種であって、すべての二等辺三角形が正三角形ではない。
反例があるので 偽
A-3
「n が8の倍数ならば、n は2の倍数である」
この命題は真か偽か。
✓ 解説 8の倍数は 8、16、24、32、40… → すべて2で割れる。
「8の倍数 ＝ 2の倍数の中の特別なもの」だから、反例は見つからない。
→ 真
A-4
「n が3の倍数ならば、n2 は9の倍数である」
この命題は真か偽か。
✓ 解説 n が3の倍数なら、n＝3a（a は自然数）と書ける。
n2＝(3a)2＝9a2 → これは9の倍数。
具体例：n＝6 のとき n2＝36＝9×4 ✓
反例は見つからないので 真
セットA：0／4問正解

セットB　追加練習

テキスト範囲外の追加問題。反例を見つける練習を増やします。

B-1
「n が偶数ならば、n は4の倍数である」
この命題は真か偽か。
✓ 解説 反例：n＝2、n＝6、n＝10 などは偶数だが、4の倍数ではない。
反例があるので 偽
B-2
「χ＝3 ならば χ2＝9 である」
この命題は真か偽か。
✓ 解説 χ＝3 なら、χ2＝32＝9。間違いなく9になる。
反例なし → 真
※「χ2＝9 ならば χ＝3」と取り違えやすいので注意（こちらは偽：χ＝－3 が反例）
B-3
「すべての長方形は正方形である」
この命題は真か偽か。
✓ 解説 反例：縦3cm、横5cmの長方形は正方形ではない。
長方形は「4つの角がすべて直角」、正方形は「それ＋すべての辺の長さが等しい」。
正方形は長方形の一種であって、逆は成り立たない。
反例があるので 偽
B-4
「n が6の倍数ならば、n は3の倍数である」
この命題は真か偽か。
✓ 解説 6の倍数は 6、12、18、24、30… → すべて3で割れる。
「6＝2×3」なので、6の倍数は必ず3でも割れる。
反例なし → 真
セットB：0／4問正解

セットC　逆向き・場合分け（応用）

命題が苦手な生徒がつまずきやすいパターンを集めました。「日本語で考える」のがコツ。

C-1
「χ＝3 ならば χ2＝9 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう χ＝3 を χ2 に代入 → 32＝9 ✓
χ が3なら、必ず χ2 は9になる。反例なし。
→ 真
※「χ2＝9 ならば χ＝3」（χ＝-3 が反例で偽）とは逆向き。向きを変えると真偽が変わる！
C-2
「n が 6 の倍数ならば、n は 3 の倍数である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう 6 の倍数は 6、12、18、24、30… → すべて 3 で割れる。
「6 ＝ 2 × 3」だから、6 の倍数は必ず 3 でも割れる。
反例なし → 真
C-3 （C-2 の逆向き）
「n が 3 の倍数ならば、n は 6 の倍数である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう 反例：n＝3、9、15、21… これらは 3 の倍数だけど、6 では割れない。
（3 の倍数の中には、6 の倍数でない数がたくさんある）
反例があるので → 偽
※C-2（6 の倍数 → 3 の倍数）は真でしたが、逆向きにすると偽になります！
C-4 （正負の積）
「ab＞0 ならば a＞0、b＞0 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう ab＞0（積がプラス）になるのは：
・(+)×(+) ＝ + ✓
・(-)×(-) ＝ + ✓ ← これも！
反例：a＝-2、b＝-3 のとき ab＝6＞0 だが、a も b も負！
反例があるので → 偽
C-5 （正負の積）
「ab＜0 ならば a＜0、b＞0 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう ab＜0（積がマイナス）になるのは：
・(-)×(+) ＝ -（a＜0、b＞0）
・(+)×(-) ＝ -（a＞0、b＜0）もOK
反例：a＝2、b＝-3 のとき ab＝-6＜0 だが、a＞0、b＜0（命題と逆）。
反例があるので → 偽
※「a＜0、b＞0」だけが ab＜0 になるわけではない。
C-6 （正負の積）
「a＞0、b＜0 ならば ab＜0 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう a が正、b が負なら、(+)×(-) ＝ マイナス。
a＞0 かつ b＜0 のとき、ab は必ず負になる。反例なし。
→ 真
※こちらは「条件 → 結果」の向きが正しいので真。C-5 とよく見比べよう。
C-7 （多解パターン）
「χ2－3χ＝0 ならば χ＝3 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう χ2－3χ＝0 を解くと：χ(χ－3)＝0 → χ＝0、χ＝3。
解は2つ（χ＝0 と χ＝3）。
反例：χ＝0 も χ2－3χ＝0 を満たすけど、χ＝3 ではない！
反例があるので → 偽
C-8 （C-7 の逆向き）
「χ＝3 ならば χ2－3χ＝0 である」
この命題は真か偽か。
✓ 解説：日本語で考えましょう χ＝3 を χ2－3χ に代入：
32－3×3 ＝ 9－9 ＝ 0 ✓
χ＝3 なら、必ず χ2－3χ＝0 になる。反例なし。
→ 真
※C-7（χ2－3χ＝0 ならば χ＝3）は偽でしたが、逆向きは真。
2次方程式は解が2つあるので、片方だけ書くと偽になりがち！
セットC：0／8問正解
