IN01 不等式の基礎

記号と性質を覚えよう

① 不等式とは？

「等式」が「$=$（イコール）」で結ばれた式（例：$3 + 5 = 8$）であるのに対し、
「不等式」は「$>$、$<$、$\geqq$、$\leqq$」などの不等号で結ばれた式のことです。

例：$5 > 3$（5は3より大きい）
例：$x \leqq 7$（$x$ は7以下）

身近な例で言えば「身長140cm以上の人だけ乗れる遊園地のアトラクション」のような「○○以上」「△△未満」といった条件を表すのが不等式です。

② 不等号の記号と意味

記号 読み方 意味 例
$>$ より大きい 左の数が大きい $5 > 3$
$<$ より小さい・未満 左の数が小さい $3 < 5$
$\geqq$ 以上 等しい場合も含めて大きい $x \geqq 7$
$\leqq$ 以下 等しい場合も含めて小さい $x \leqq 5$

★ココが大事：「以上・以下」と「より大きい・より小さい」の違い

  • $\geqq$（以上）、$\leqq$（以下）：その数を含む（横棒2本がその印！）
  • $>$（より大きい）、$<$（より小さい）：その数を含まない

例：$x \geqq 5$ には $x = 5$ が含まれるが、$x > 5$ には $x = 5$ は含まれない。

③ 不等式の性質（とても大切！）

不等式には、4つの大切な性質があります。次の単元（IN02）で実際に解くときに必ず使います。

性質①：両辺に同じ数を足しても、不等号の向きは変わらない

$a < b$ ならば $a + c < b + c$

例：$3 < 5$ の両辺に $2$ を足しても、$3+2 < 5+2$、つまり $5 < 7$。向きは同じ。

性質②：両辺から同じ数を引いても、不等号の向きは変わらない

$a < b$ ならば $a - c < b - c$

例：$3 < 5$ の両辺から $1$ を引いても、$3-1 < 5-1$、つまり $2 < 4$。向きは同じ。

性質③：両辺に「正の数」をかける・割る → 向きは変わらない

$a < b$ で $c > 0$ ならば $a \times c < b \times c$、$a \div c < b \div c$

例：$3 < 5$ の両辺に $2$ をかけても、$3 \times 2 < 5 \times 2$、つまり $6 < 10$。向きは同じ。

⚠ 性質④（最重要・落とし穴）：両辺に「負の数」をかける・割ると、不等号の向きが反転する！

$a < b$ で $c < 0$ ならば $a \times c > b \times c$、$a \div c > b \div c$

例：$3 < 5$ の両辺に $-1$ をかけると、$-3 > -5$。
→ 数直線で見ると、$-3$ は $-5$ より右側（大きい方）にあります。
→ だから不等号の向きが 逆になるのです！

④ 数直線でイメージする

不等式の解を視覚的にイメージするには 数直線 が便利です。

$x \geqq 2$ は「$2$ 以上のすべての数」を表します。$2$ も含むので、数直線では $2$ の点を ●（黒丸） で表します。$x > 2$ なら、$2$ は含まないので ○（白丸） になります。

⑤ 単元のゴール

🎯 できるようになること

  • $>$、$<$、$\geqq$、$\leqq$ の意味を正しく言える
  • 「以上・以下・より大きい・より小さい」を不等式で表せる
  • 不等式の4つの性質を理解する
  • 「負の数をかけたり割ったりすると向きが反転する」ことを覚える
