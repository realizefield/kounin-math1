① $x^2$ の係数が「1ではない」展開
📌 EF01とどう違う？
EF01では $(x+a)(x+b)$ — つまり $x$ の係数が両方とも1 でした。
EF10では $x$ の係数が1でない 場合：$(2x+5)(3x-7)$ のような展開を扱います。
高認では，こちらのタイプ（係数が1ではない）が 頻出 です！
📌 公式
$(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
例)$(3x+5)(2x-7)$ を展開する
①両端
$x^2$の項：$3x \times 2x = 6x^2$　／　定数項：$5 \times (-7) = -35$
②真ん中
外×外＋内×内：$3x \times (-7) + 5 \times 2x = -21x + 10x = -11x$
合体
$6x^2 - 11x - 35$
$6x^2 - 11x - 35$
② 真ん中の項は「外×外＋内×内」
📌 真ん中の項の作り方
両端（$x^2$の項と定数項）は，それぞれの端どうしを掛けるだけで簡単。
難しいのは「真ん中の $x$ の項」。これは 2つの掛け算をたす ことで作る。
その2つとは ——
$(ax+b)(cx+d)$ — 真ん中の項のしくみ
$(\overbrace{a}^{\text{外}} x + b)(c x + \overbrace{d}^{\text{外}})$　← 外×外＝$adx$
$(a x + \underbrace{b}_{\text{内}})(\underbrace{c}_{\text{内}} x + d)$　← 内×内＝$bcx$
🔴 外×外
$a \times d \times x$
🔵 内×内
$b \times c \times x$
真ん中の項 ＝ $ad x$ ＋ $bc x$ ＝ $(ad+bc)x$
💡 「外×外」「内×内」とは？
$(ax+b)(cx+d)$ を見たときに：
・外×外：いちばん 外側 どうし → $ax$ と $d$
・内×内：いちばん 内側 どうし → $b$ と $cx$
この2つを たして 真ん中の $x$ の項を作る。
③ 解き方の手順
1
$x^2$ の項を作る　→　$ax \times cx = acx^2$
2
定数項を作る　→　$b \times d = bd$
3
真ん中の項＝外×外＋内×内　→　$adx + bcx = (ad+bc)x$
4
3つを合わせる　→　$acx^2 + (ad+bc)x + bd$
④ 文字が2種類のパターン
例)$(4x+y)(3x-2y)$ を展開する
$x^2$
$4x \times 3x = 12x^2$
真ん中
外×外：$4x \times (-2y) = -8xy$，内×内：$y \times 3x = 3xy$
たす
$-8xy + 3xy = -5xy$
$y^2$
$y \times (-2y) = -2y^2$
合体
$12x^2 - 5xy - 2y^2$
$12x^2 - 5xy - 2y^2$
$y$ も「定数のかわり」と見れば，公式の使い方は同じ！
ただし最後の項は $bd$ ではなく $y^2$ の項になる。
⑤ 符号のミスに注意
例)$(3x-4)(2x+5)$ を展開する
$x^2$
$3x \times 2x = 6x^2$
外×外
$3x \times (+5) = +15x$
内×内
$(-4) \times 2x = -8x$
真ん中
$15x + (-8x) = +7x$
定数項
$(-4) \times (+5) = -20$
答え
$6x^2 + 7x - 20$
$6x^2 + 7x - 20$
符号は その項についている符号ごと 掛ける！
$-4$ なら $-4$ のまま，$-2y$ なら $-2y$ のまま掛ける。
⑥ 高認頻出パターン
例)$(5x+y)(x-7y)$ を展開する
$x^2$
$5x \times x = 5x^2$
外×外
$5x \times (-7y) = -35xy$
内×内
$y \times x = xy$
真ん中
$-35xy + xy = -34xy$
$y^2$
$y \times (-7y) = -7y^2$
$5x^2 - 34xy - 7y^2$
例)$(7x+2y)(x-3y)$ を展開する
$x^2$
$7x \times x = 7x^2$
真ん中
外×外：$-21xy$，内×内：$2xy$ → $-19xy$
$y^2$
$2y \times (-3y) = -6y^2$
$7x^2 - 19xy - 6y^2$
📌 まとめ
  • EF10：$x^2$ の係数が1ではない場合の展開
  • 公式：$(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
  • 真ん中の項は 外×外＋内×内 でつくる
  • 両端（$x^2$と定数項）はカンタン，真ん中の項に注意
  • 符号は そのまま 持って計算
  • これは EF11〜13（たすき掛け因数分解）の 基礎 になる！
