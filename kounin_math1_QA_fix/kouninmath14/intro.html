📌 「公式は知ってるけど，どれを使うかわからない」を解決！
問題を見たとき，どこを見れば，どの公式を使えばよいか — このマップで一目瞭然！
ステップ1：何をする問題？
STEP 1
問題は 3種類のどれ ？
🟢 ① 展開（カッコを開く）
$(2x+3)(x-1)$ を展開せよ
🔵 ② 因数分解（カッコにまとめる）
$x^2 + 5x + 6$ を因数分解せよ
🟠 ③ 文字式の計算
$A=x^2+1$，$B=x-2$ のとき $A+B$ を計算
問題文の 動詞 を見るだけ！
「展開」「因数分解」「計算」のキーワードで分類できる。
ステップ2：展開のときの判別
🟢 展開　5パターン
同じカタマリが2回ある？ → A置換 例：$(2a-b)(2a-b+1)$ や $(a+b)(a+b+3)$
→ $(2a-b)$ や $(a+b)$ を $A$ と置く（EF04-2）
$(○+a)(○-a)$ の形？ → 和と差の積 例：$(a+b+2c)(a+b-2c)$
→ $(a+b)=A$ と置けば $(A+2c)(A-2c) = A^2-(2c)^2$（EF03/EF04-2）
$(○+a)^2$ の形？ → 平方公式 例：$(a^2+b)^2$
→ $(a+b)^2 = a^2 + 2ab + b^2$ の公式を使う（EF02）
$(ax+b)(cx+d)$ — $x$ の係数が1ではない？ → 展開公式① 例：$(3x+5)(2x-7)$
→ 外×外＋内×内（EF10）
$(x+a)(x+b)$ — 両方とも係数1？ → 展開公式 例：$(x+3)(x-2)$
→ $x^2 + (a+b)x + ab$ の公式（EF01）
⚠️ 展開で 最重要 なのは「同じカタマリ」を見つけること！
高認の出題傾向を見ると，A置換（同じカタマリを置き換え）が圧倒的に多い。
まず「同じものが2回出てないか？」をチェックする習慣をつけよう。
🌱 A置換が難しいと感じたら…
A置換に気づけなくても，そのまま全部それぞれ展開すれば必ず正解にたどり着けます！
例：$(2a-b)(2a-b+1)$ →　$2a \times 2a + 2a \times (-b) + 2a \times 1 + (-b) \times 2a + (-b) \times (-b) + (-b) \times 1$
一つひとつ丁寧に掛けて，最後にまとめれば OK。
A置換は「速く解く近道」であって，使えなくても問題は解けるから安心して！
ステップ3：因数分解のときの判別
🔵 因数分解　5パターン
同じカタマリが2回ある？ → A置換 例：$(x+4)^2 - 7(x+4)$
→ $(x+4)$ を $A$ と置く（EF09）
$a^2 - b^2$ の形（2乗の差）？ → 和と差の積 例：$x^2 - 9$
→ $(a+b)(a-b)$ の形に（EF05）
共通因数がある？ → 共通因数 例：$3x^2 + 6x$
→ 共通因数 $3x$ をくくり出す（EF08）
$x^2 + bx + c$ — $x^2$ の係数が 1 ？ → たして・かけて 例：$x^2 + 5x + 6 = (x+2)(x+3)$
→ 2数を見つける（EF06系）
$ax^2 + bx + c$ — $x^2$ の係数が 1ではない ？ → たすき掛け 例：$2x^2 + 5x + 3 = (2x+3)(x+1)$
→ たすき掛けで組み合わせを見つける（EF11/12/13）
⭐ 高認では このタイプが最頻出！
ステップ4：たすき掛けの3パターン
$x^2$ の係数が1ではない時，定数項と係数の符号 でさらに分類：
🌳 たすき掛けの分岐
+
定数項 + ， 係数 + → 両プラス型 EF11
例：$2x^2 + 5x + 3 = (2x+3)(x+1)$
−
定数項 + ， 係数 − → 両マイナス型 EF12
例：$6x^2 - 7x + 2 = (3x-2)(2x-1)$
±
定数項 − （係数の符号は問わず）→ 符号が逆型 EF13
例：$2x^2 + 5x - 3 = (2x-1)(x+3)$
ステップ5：文字式の計算
🟠 文字式の加減　基本
$A+B$，$A-B$，$3A+B$ などの計算 例：$A=x^2+x-2$，$B=-3x^2-3x-1$ のとき $A-B$ を計算
→ $A-B = (x^2+x-2) - (-3x^2-3x-1) = 4x^2+4x-1$
注意：引き算は 各項の符号を反転
高認では R5-2, R4-2, R3-1, R2-1, R1-2 で出題 本番で頻出 → 落ち着いて符号に注意するだけ。難しい公式は不要！
📋 問題を見たときの確認手順
⭐ この順番でチェックすれば必ず判別できる！
  1. 問題文を読み，「展開」「因数分解」「計算」のどれか確認
    → 動詞でわかる
  2. 同じカタマリが2回出てないか確認
    → あれば「A置換」で決まり
  3. $(○+a)(○-a)$ や $(○+a)^2$ の形か確認
    → あれば「和と差の積」「平方公式」
  4. 因数分解なら，$x^2$ の係数が1か確認
    → 1なら EF06系，1ではないなら たすき掛け
  5. たすき掛けなら，定数項と係数の符号を見る
    → EF11 / EF12 / EF13 のどれか分かる
💡 迷ったら「カタマリ」と「係数」の確認！
迷ったときの第一手は，「同じカタマリが2回ないか」 のチェック。
次に 「$x^2$ の係数が1か1ではないか」。この2つでほぼ判別できる！
